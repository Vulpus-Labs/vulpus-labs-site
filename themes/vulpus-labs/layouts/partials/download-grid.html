These binaries are unsigned

macOS quarantines anything downloaded from the web, and a quarantined plugin is skipped silently by your DAW's scan — it simply never appears. After unpacking and copying the plugin into place, clear the flag:

{{ $clap := "" }}{{ $vst3 := "" }} {{ with .install }}{{ $clap = .clap }}{{ $vst3 = .vst3 }}{{ end }} 
{{ with $clap }}xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/CLAP/{{ . }}
{{ end }}{{ with $vst3 }}xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/{{ . }}{{ end }}{{ if not $clap }}xattr -dr com.apple.quarantine path/to/the/plugin{{ end }}

Windows shows a SmartScreen warning on first load instead — choose More info → Run anyway.
