Installing

Unzip the download and copy {{ $clap }} into your CLAP folder{{ with $vst3 }}, or {{ . }} into your VST3 folder{{ end }}, then rescan plugins in your DAW:

{{ if $vst3 }}macOS     CLAP  ~/Library/Audio/Plug-Ins/CLAP/
          VST3  ~/Library/Audio/Plug-Ins/VST3/
Windows   CLAP  C:\Program Files\Common Files\CLAP\
          VST3  C:\Program Files\Common Files\VST3\
Linux     CLAP  ~/.clap/
          VST3  ~/.vst3/{{ else }}macOS     ~/Library/Audio/Plug-Ins/CLAP/
Windows   C:\Program Files\Common Files\CLAP\
Linux     ~/.clap/{{ end }}

The macOS build is signed and notarized by Apple, so it loads without any extra steps. The Windows and Linux builds are not signed. If Windows blocks the plugin, right-click the downloaded zip, choose Properties, tick Unblock and unzip it again.

{{ else }}

These binaries are unsigned

macOS quarantines anything downloaded from the web, and a quarantined plugin is skipped silently by your DAW's scan — it simply never appears. After unpacking and copying the plugin into place, clear the flag:

{{ $clap := "" }}{{ $vst3 := "" }} {{ with .install }}{{ $clap = .clap }}{{ $vst3 = .vst3 }}{{ end }} 
{{ with $clap }}xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/CLAP/{{ . }}
{{ end }}{{ with $vst3 }}xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/{{ . }}{{ end }}{{ if not $clap }}xattr -dr com.apple.quarantine path/to/the/plugin{{ end }}

Windows shows a SmartScreen warning on first load instead — choose More info → Run anyway.
